# Security Policy

## Supported versions

Security fixes ship in the latest release. Older releases are not maintained on their own branches.

## Reporting a vulnerability

Report it privately: [Open a security advisory](https://github.com/axiscoretech/ai-hub/security/advisories/new).

Include the app version, the operating system, and what an attacker can do. Do not open a public issue for an unfixed vulnerability. Do not include WireGuard configs, private keys, cookies, session files, or dashboard tokens.

You will get a reply on the advisory. A fix is published only after the report is confirmed.

## What stays on the computer

Logins, encrypted WireGuard configs, and Compare tasks stay in the app data folder. The README section on privacy names those paths. A report that needs one of those files should describe it, not attach it.
